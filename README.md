# Portafolio · Antonio Cruz

Sitio personal de **Eduardo Antonio Cruz Bolaños** (Antonio Cruz), desarrollador full stack de Guatemala con enfoque en backend, APIs e IA aplicada.

**Sitio:** https://toto05-a.github.io

## Qué incluye

- Proyectos recientes con enlace a su repositorio y demos de interfaz.
- Formación, habilidades y CV en PDF descargable.
- Español e inglés, tema claro y oscuro, diseño adaptable a móvil.

## Tecnologías

HTML5, CSS3 y JavaScript sin frameworks ni proceso de build. Se publica con GitHub Pages desde la rama `main`.

## Ejecutarlo en local

```bash
python -m http.server 8000
```

Luego abre http://localhost:8000.

## Estructura

```
index.html            Página principal
css/                  Estilos (style.css) y ajustes responsive (responsive.css)
js/translations.js    Todos los textos en ES y EN
js/main.js            Idioma, tema, menú, pestañas y animaciones
assets/               Imágenes, iconos, demos y el CV en PDF
```

Para cambiar un texto, edita la clave en `js/translations.js` en los dos idiomas.
